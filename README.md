# Global Inflammatory Bowel Disease Gut Microbiome Analysis

Reproducible R code for all main figures in the manuscript:

> **Global patterns of gut microbiome composition and their associations with IBD epidemiological stages**

## Overview

This repository contains the R scripts that reproduce Figures 1–7 of the manuscript. The analysis integrates global IBD epidemiological data with gut microbiome profiling across six international cohorts to characterize microbial signatures of IBD onset and progression.

| Script | Figure | Description |
|--------|--------|-------------|
| `FIG1A-J.R` | Figure 1 | Global IBD prevalence/incidence maps, alpha-diversity, PCoA, and MDS density by epidemiological stage |
| `FIG2A-D.R` | Figure 2 | Global gut microbiome phylum composition by region and stage |
| `FIG3A-F.R` | Figure 3 | Differentially abundant taxa between IBD stage-associated regions (bubble charts, heatmaps, ridgeline plots, LEfSe) |
| `FIG4A-J.R` | Figure 4 | Systematic microbiome differences between IBD subtypes (UC/CD) and healthy controls — genus and species level |
| `FIG5A-D.R` | Figure 5 | Metabolic pathway analysis and microbial co-occurrence networks |
| `FIG6A-I.R` | Figure 6 | Machine learning (LASSO + Random Forest) for IBD stage prediction using gut microbiome features |
| `FIG7A-I.R` | Figure 7 | Phylogenetic and phenotypic characterization of IBD-associated species and strain-level geography |

## Data Availability

### Supplementary Tables (main input data)

All primary input data files correspond to the **Supplementary Tables published with the manuscript**. Download the supplementary tables from the journal website and place them in the same directory as the script before running.

Files named `Supplementary_Table_XX_*.csv/.tsv` in the input file list below refer directly to the numbered supplementary tables in the paper.

### Intermediate processed files

Some scripts additionally require pre-computed intermediate files (`.rds` / `.RData`) that are generated by the upstream bioinformatic pipeline described in the Methods section of the manuscript. These include:

| File | Generated by | Used by |

| `nmds.rds`, `pcoa_points.rds` | Ordination analysis | FIG1 |

| `genus.rds` | Taxonomic aggregation pipeline | FIG3 |
| `lmm-IBD.RData` | Linear mixed model fitting (Methods: LMM) | FIG5 |
| `Figure6_tenfold_workspace.RData` | 10-fold cross-validation (Methods: ML) | FIG6 |
| `MIRS.RData`, `lasso.RData` | MIRS / LASSO model fitting | FIG6 |

Readers wishing to reproduce these intermediate files should follow the pipeline described in the Methods section. For direct access to these files, please contact the corresponding author.

## Usage

Each script is self-contained. Place the required input files in the **same directory** as the script, then run:

```r
# Example: reproduce Figure 1
source("FIG1A-J.R")
```

Or from the command line:

```bash
Rscript FIG1A-J.R
```

Output PDF files will be saved to the same directory as the script.

## Output

Each script produces publication-quality PDF panels corresponding to the figure panels in the manuscript, along with any supplementary figures and tables.
